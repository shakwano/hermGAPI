Privacy Policy

Last updated: 16 October 2026

This policy covers Hermes Agent, a private automation application operated by a single individual on a private home server. It is not a public or commercial service.

What data is accessed

With the operator's explicit authorisation, the application accesses the operator's own Google account data: calendar events and, where enabled, email and drive file metadata. It does not access data belonging to any other person.

How it is used

The data is used solely to provide personal reminders and notifications to the operator — for example, reading a calendar entry to send a timely reminder before a scheduled event.

Storage

Data is stored only on the operator's private home server and is not transmitted to any third party. OAuth credentials are kept in a local file readable only by the operator's system account.

Sharing

No data is sold, shared, rented, or disclosed to advertisers or any third party.

Google API Services User Data Policy

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The operator may revoke this application's access at any time at myaccount.google.com/permissions. Revoking access immediately ends all data access by the application.
